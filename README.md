## 📖 Overview

This repository documents my personal learning journey and practical implementations using **DSPy**.

DSPy allows you to program LLMs by describing the *what* (the task/pipeline) rather than the *how* (specific prompts, few-shot examples, etc.), enabling automatic, data-driven optimization of your language pipelines.

This collection of Jupyter Notebooks and Python scripts is a resource for anyone looking to understand and master DSPy's core concepts.

## ✨ Key Features & Learnings

* **Modular Pipeline Design:** Learn how to break down complex LLM tasks into simple, composable **Modules** (e.g., `ChainOfThought`, `ReAct`).
* **Structured Learning:** Content is organized into a `basics/` directory for fundamental concepts.
* **Jupyter-First Approach:** Nearly all examples are presented in Jupyter Notebooks for an interactive and accessible learning experience.
